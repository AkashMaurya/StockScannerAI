🚀 HOW TO USE
================================================================================

STEP 1: TRAIN THE AI MODEL
---------------------------
1. Open the app at http://localhost:8502
2. Look at the left sidebar under "🤖 AI Model"
3. Click "🧠 Train AI Model" button
4. Wait 2-5 minutes while it:
   - Fetches 60-day historical data for top 50 stocks
   - Calculates 14 technical indicators for each day
   - Creates training labels based on future price movement
   - Trains Gradient Boosting model
   - Validates accuracy on test set
5. See accuracy displayed (e.g., "✅ Model Trained - Accuracy: 78.5%")

STEP 2: SCAN STOCKS WITH AI
----------------------------
1. Go to "Scanner" tab
2. Select scan type: Intraday, Delivery, or Swing Trading
3. Choose risk level: Low, Medium, or High
4. OPTIONAL: Search for specific stock using dropdown
5. OPTIONAL: Filter by sector (Banking, IT, Pharma, etc.)
6. Click "🚀 Start Scanning"
7. AI model analyzes each stock using 60-day historical data
8. Results show:
   - Signal (BUY/SELL/HOLD)
   - Confidence % (how sure the AI is)
   - Entry, Target, Stop Loss prices
   - AI Score (0-100)
   - Model Accuracy

STEP 3: VIEW DETAILED ANALYSIS
-------------------------------
1. Go to "Stock Details & Charts" tab
2. Select any stock from dropdown
3. Click "Load Stock Data"
4. See:
   - Live price metrics

   - Interactive chart with support/resistance lines

📈 RESULTS INTERPRETATION
================================================================================

**BUY Signal**
- AI predicts price will go UP in next 5 days
- Confidence: How sure the AI is (50-100%)
- Entry: Current price to buy at
- Target: Expected profit level
- Stop Loss: Exit if price falls to this level

**SELL Signal**
- AI predicts price will go DOWN in next 5 days
- Confidence: How sure the AI is (50-100%)
- Entry: Current price to sell at
- Target: Expected lower price
- Stop Loss: Exit if price rises to this level

**HOLD Signal**
- AI predicts no significant movement
- Wait for better opportunity
- Not recommended for trading right now

**Confidence Percentage**
- 90-100%: Very High Confidence - Strong signal
- 70-89%: High Confidence - Good signal
- 50-69%: Moderate Confidence - Proceed with caution
- Below 50%: Low Confidence - Avoid

**Model Accuracy**
- Displayed in sidebar and results
- Shows how accurate the AI model is on test data
- Typical range: 70-85%
- Higher is better

================================================================================
🔧 TECHNICAL DETAILS
================================================================================

**Machine Learning Pipeline:**
1. Data Collection: 60-day OHLCV data from Yahoo Finance
2. Feature Engineering: Calculate 14 technical indicators
3. Label Creation: Analyze future 5-day price movement
4. Model Training: Gradient Boosting with 80/20 train/test split
5. Prediction: Real-time analysis using trained model
6. Confidence: Probability from model's predict_proba()

**Why Gradient Boosting?**
- Better than Random Forest for time-series financial data
- Handles non-linear relationships well
- Provides probability estimates for confidence
- Less prone to overfitting with proper max_depth

**Feature Scaling:**
- StandardScaler used to normalize all features
- Ensures all indicators contribute equally
- Improves model convergence and accuracy

**Fallback Mechanism:**
- If not enough historical data: Uses rule-based model
- If ML model not trained: Uses technical analysis rules
- Ensures app always provides recommendations

📞 TROUBLESHOOTING

Solution: Retrain with more stocks or wait for better market conditions

**Issue: Model training fails**
Solution: Check internet connection (needs to fetch historical data)

Solution: ML model not trained - click "Train AI Model" in sidebar

**Issue: Charts not showing**
Solution: Refresh the page and ensure yfinance is installed
